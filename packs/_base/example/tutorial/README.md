# Учебные схемы для C++

Все схемы каталога используют `Make(cpp)`. Откройте урок, сохраните копию
в пользовательский каталог и соберите её. `Index.sha` выводит список уроков.
`intro.sha` — документ Core: его не нужно собирать или запускать.

| Схема | Что демонстрирует |
|---|---|
| Hub | Разветвление события и порядок вызовов трёх обработчиков |
| Check | Выбор ветви во время компиляции; не элемент CheckBox |
| EventFromData | Ленивое вычисление значения при каждом запросе |
| GlobalVar | Разделяемое состояние в пределах проекта/окна |
| CableHelp | Именованные поля кабеля и независимое изменение поля |
| Element | Параметризованная функция фильтрации имён файлов |
| MultiElementEx | Создание, выбор, удаление независимых экземпляров |
| MultiThread | Неоднородный MT-набор значений; не потоки ОС |
| Stack | Стек LIFO с проверкой пустого состояния |
| Types | Именованный тип, чтение, изменение, добавление и удаление полей |
| Informer | Различие между пояснением в редакторе и выводом программы |
| DLL | Библиотека с экспортом `hiasm_run`; нужен вызывающий процесс |
| Index | Указатель доступных уроков |

Где готового компонента C++ ещё нет, сценарий показан через `Code`.
Свойства `Code` и `Expression` содержат C++; `input` — входное значение
(`std::string`, если события без данных), `onResult` — результат выражения. Область действия кода
локальная; состояние между событиями хранится в runtime проекта.
Пример `Element` показывает параметризацию функции и не воспроизводит
полностью редактирование внешних свойств пользовательского компонента.

Адаптации сохраняют учебную тему оригиналов. Они не заменяют полный
перенос одноимённых Delphi-компонентов, редакторов вложенных схем
и форматов кабелей. Оригиналы находятся в исследовательском архиве,
описанном в `packs/_base/README.md`.

`rtcg_test` проверяет сборку всех 13 уроков, точный вывод 12 консольных
программ и загрузку/вызов экспорта библиотеки.
