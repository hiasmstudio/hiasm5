# Core: приветствие и учебные схемы

`_base` сохраняет имя пакета Core из HiAsm 4. Схемы-документы с
`Make(_base)` предназначены для чтения в редакторе: команды сборки, запуска
и редактора формы для них недоступны. Внутренние формы IDE на `hcTplForm`
и `hcTplDialog` по-прежнему исполняются встроенным движком.

## Структура

- `example/tutorial/intro.sha` — базовое приветствие; локализованная замена
  находится в `lang/<язык>/example/tutorial/intro.sha`.
- `lang/<язык>/conf/*.lang` — переводы описаний элементов, свойств и точек;
  имя `.lang` совпадает с исходным файлом конфигурации в `conf/`.
- `lang/<язык>/example/` — локализованные копии учебных схем, когда перевод
  меняет текст самой схемы.
- `example/tutorial/` — 14 учебных примеров, адаптированных под `Make(cpp)`.
- `example/plugs/` — три самостоятельных демонстрации GTK4 на `Make(cpp)`.
- `conf/`, `new/`, `elements.db` и `elements.sql` — конфигурации, шаблоны и каталог элементов Core.

Палитра, конфигурации, значки и шаблоны Core берутся из этого каталога.
Адаптированные примеры используют `Make(cpp)` и находятся отдельно в
`example/tutorial` и `example/plugs`. Исходные бинарники Delphi в сборку не входят;
результаты сборки примеров исключаются из поставки.

## Первый запуск

Приветствие открывается один раз для каждого пользовательского профиля.
Новый профиль выбирает русский или английский язык по настройкам системы;
для остальных языков используется английский. Уже выбранный в настройках
IDE язык сохраняется. При отсутствии или повреждении русской схемы IDE
пытается открыть английскую. Отметка `welcome-core-v1.seen` записывается
в пользовательский каталог `.hiasm` только после успешного открытия.

Приветствие можно открыть повторно через «Файл → Открыть», выбрав
`packs/_base/lang/ru/example/tutorial/intro.sha` или базовую
`packs/_base/example/tutorial/intro.sha`.
Изменения установленных схем сохраняйте через «Сохранить как»: обычное
«Сохранить» также предлагает сохранить отдельную копию.

## Запускаемые уроки

Откройте пример из `example/tutorial` или `example/plugs` и сначала сохраните
копию в свою папку через «Сохранить как». Затем соберите и запустите её.
Используется пакет «Приложение на C++», RTCG и GCC C++17; для трёх
графических демонстраций нужны development-библиотеки GTK4. Библиотека
`DLL.sha` экспортирует `hiasm_run` и запускается вызывающим приложением,
поэтому кнопка запуска IDE для неё отключена.

Пояснения и ограничения приведены в README соответствующих каталогов.
Это адаптации учебных сценариев, а не полная совместимость компонентов
Delphi или двоичного интерфейса плагинов HiAsm 4.

## Архив оригиналов

Все 489 исходных файлов скопированного пакета, включая CP1251-схемы,
конфигурации, базы, значки, `chat.dll`, `std.dll` и `panex.exe`, сохранены
без изменений в `MARKDOWN/HIASM4_RESEARCH/core-original.zip` относительно
корня репозитория. Контрольная сумма — в `core-original.sha256` рядом
с архивом. Архив не устанавливается вместе с программой.

## Проверки

`core_welcome_test` проверяет локализацию, первый запуск, восстановление
вкладок, запасную английскую схему, сохранение копии, границы текста
и запрет сборки документов. `rtcg_test` собирает все 17 адаптаций,
сравнивает вывод консольных уроков, вызывает экспорт библиотеки
и проверяет события и состояние виджетов демонстраций GTK4.
