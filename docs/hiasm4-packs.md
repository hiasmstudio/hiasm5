# Подключение пакетов HiAsm 4

Этот раздел описывает каталог и мост прежней IDE. Окно Qt работает с поставляемыми пакетами. Подключение внешних установок HiAsm 4 остаётся в [чеклисте переноса](../MARKDOWN/CHECKLIST.md).

В `packs/_hiasm4/paths.ini` укажите по одной папке установки HiAsm 4 на строку.
Каждая должна содержать `Elements/<пакет>/Elements.db` и `conf`.
Поддерживаются комментарии `#`/`;`, кавычки, относительные пути,
`%APPDATA%`, переменные окружения и `~`.
Переменная `HIASM4_ROOTS` заменяет конфиг; несколько путей разделяются `;`.
После изменения путей перезапустите HiAsm.

HiAsm показывает группы, иконки, конфигурации, шаблоны и исходники внешнего
пакета. CP1251 преобразуется в UTF-8 при чтении. При совпадении имени приоритет
имеет собственный пакет HiAsm 5.

Внешняя установка открывается для чтения. Сохраните схему или текст через
«Сохранить как» вне её каталога; копия записывается в UTF-8.
Создание элементов и групп непосредственно во внешней установке отключено.
Свойства старых ресурсов сохраняются как исходные данные; их редактирование
и передача в генератор ещё не реализованы.

Сборка старого Delphi-пакета пока недоступна:
32-разрядные DLL требуют отдельного x86-процесса и протокола CGT.
Установка Wine сама по себе эту совместимость не добавляет.

Редактор формы (кнопка на панели инструментов) работает для схем, в которых
есть элемент с `[Edit] Class=Form` (например, `MainForm`). В HiAsm 4 он был
встроен в HiAsm.exe, поэтому IDE показывает форму сама: отдельным окном с
рамкой из свойства `BorderStyle` (те же стили окна, что в `hiMainForm.pas`),
заголовком `Caption`, цветом `Color` и размером `Width`/`Height`
(с учётом `ClientSize`). Элементы с `[Edit]` можно выделять, перемещать и
растягивать мышью; перемещение и изменение размера окна меняют
`Left`/`Top`/`Width`/`Height` формы. Вложенные контейнеры (ChildPanel и т.п.)
пока показываются прямоугольником без содержимого.

SVN-команды палитры работают для конфигураций в рабочей копии при наличии
клиента `svn` в PATH (либо `HIASM_SVN`). После обновления перезапустите IDE,
чтобы перечитать определения; открытые схемы сохраняют загруженную конфигурацию.
